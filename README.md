# TIME-MANAGER

An open-source Flutter time management app that lets you manage tasks and view them on a calendar.

## Features

- Add tasks with due dates
- Toggle task completion
- View tasks in a list or calendar view
- Simple state management with `provider`

## Getting Started

Ensure you have [Flutter](https://flutter.dev) installed. Then run:

```bash
flutter pub get
flutter run
```

This will build and launch the application on your connected device or emulator.
